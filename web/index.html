2D Network Matrix & Dynamic Sub-Row Custody Striping

Each cell [NetRow r, NetCol 0] manages 16 data sub-rows (dataRow = r, r+8, ..., r+120). When a cell has $M \ge 2$ nodes, each (blockID, subRow) selects 1 Primary (4 pieces) + 1 Backup (1 piece), while remaining nodes act as Non-Custody (1 piece).
